## 5-minute checklist

1. **Live feed** shows ● LIVE and recent timestamp  
2. **No macro banner** (or trade half size)  
3. **News** supports your direction (BULLISH/BEARISH)  
4. **Prediction** confidence ≥ 50%, clear target & stop  
5. **Calculate** position size (formulas below)

---

## Formulas

### Risk amount
```
Risk ₹ = Account × Risk%
Example: ₹10,00,000 × 1% = ₹10,000
```

### Position size
```
Shares = Risk ₹ ÷ |Entry − Stop|
Example: ₹10,000 ÷ ₹50 = 200 shares
```

### Risk : Reward
```
R:R = |Target − Entry| ÷ |Entry − Stop|
Prefer R:R ≥ 1.5
```

## Confidence → action

| Confidence | Action |
|------------|--------|
| 70%+ | Full planned size (if macro clear) |
| 50–69% | Half size |
| &lt; 50% | No trade |
| Macro shock ON | Avoid index longs, reduce size |
